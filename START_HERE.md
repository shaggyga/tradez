# Start here

Read [README.md](README.md) for cloning and local setup, then
[FOREX_HANDOFF.md](FOREX_HANDOFF.md) for the current-work protocol.

The Git root is this Forex workspace. `trad/` and the current engineering directory
are sibling components. The shared Vault supplies the design, queue, ownership and
review records; each machine supplies its own local Vault path.

Run the read-only operational preflight before research or routine computation.
See [operational checks](docs/OPERATIONAL_PREFLIGHT.md) and
[existing-artifact reuse](docs/ARTIFACT_REUSE.md). A missing local model requires
retrieval and identity verification; it does not authorize retraining.

Prior instructions are preserved in [history](docs/history/START_HERE_before_operations_20260923.md).
