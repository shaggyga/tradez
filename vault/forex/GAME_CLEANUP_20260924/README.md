# C-drive game and duplicate cleanup

User authorized removal of Outlaws, Overwatch, Modern Warfare Remastered and duplicates.
The C-drive Outlaws and Overwatch directories were removed. The separately registered
D-drive Outlaws installation and external save folders were not touched. A further
245 identical restore input files were retired only after matching SHA-256 with retained
originals. Their journal supports exact byte recovery using the Git recovery helper.

Modern Warfare Remastered remains: Windows denied access to 119 files. Automatic
approval review rejected the attempted ownership change with the generic reason
"blocked by policy". No ownership change was executed. These remaining files require
an administrator to finish deletion from:
C:\Program Files (x86)\Steam\steamapps\common\Call of Duty Modern Warfare Remastered

Overwatch's game files are gone, but its stale Windows uninstall registration also
requires administrator/launcher cleanup. RESULT.json reports actual free bytes and
remaining bytes. Scientific source, queue and sealed research packets are unchanged.
