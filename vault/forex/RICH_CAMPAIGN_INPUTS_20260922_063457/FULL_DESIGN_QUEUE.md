## Acceptance rule for every pending change

A fix to infrastructure does not count as new market evidence. A new model must name the closest previous experiment, material difference, matched baseline, stopping rule and independent confirmation route.

No pending change is complete solely because a file exists, tests of a different component pass, an import works, or a report says “retired.” Preserve useful negative findings without promoting compromised diagnostics into valid negatives or retiring entire model families.
