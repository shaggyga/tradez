## The intended system

The user's aim was rolling observations across all 68 FX pairs: feature changes mapped to subsequent pair movement, a forecast curve useful for position management, and eventually official-release currency strength combined with technical entry/exit information. Strongest-versus-weakest currency pairing, news-only/price-only/combined comparisons, and multiple practice environments already appear in the project history.

The immediate reorientation is price/technical first. News evidence stays preserved for its later phase. A model being unprofitable does not excuse missing feature observations, and a feature being computed does not make it a useful trading signal.

## Results: preserve both negative findings and limited leads

No audited setup has established dependable after-cost profit. That is narrower than saying every feature has zero relationship to price.

- ARIMA H1: 49.95% direction, -1.7974 native pips mean selected trade in its retained report; no-change error was slightly better. Other ARIMA generations are related diagnostics, not independent holdouts.
- Recovered HGB opportunity model using 164 inputs: approximately 0.6822 development AUC for either-side two-hour opportunities on 15 pairs. That is not signed-direction accuracy.
- A two-stage diagnostic reached 55.15% direction while remaining about -1.371 pips after costs.
- Unified 795: 49.416% direction; signed MAE slightly worse than zero. Corrected MA643/combined667 did not beat compact24 in the nine-cell comparison; compact24 did not establish a profitable setup either.
- The repaired 631-feature comparison won direction in two of six cells; its lone positive selected return failed added-cost/delay checks.
- An older H60 cross-currency result averaged +0.308 bps, but robustness was weak and concentrated in USD/HUF.
- Calibration improved in all eight reported comparisons, while most selected policies still lost.
- The six September 9 actual practice trades all lost, totaling $0.3175. They are separate from simulation returns and research quote entries.

## Reorientation

Use the existing pieces to define one rolling technical dataset before further model changes: per-pair completed candle inputs; explicit elapsed windows, gaps and minimum support; stable feature IDs and deduplication; causal historical/live parity; durable observations; original-clock future outcomes including quiet controls. Decide the minimal all-68 feature set explicitly and mark unsupported inputs unavailable.

Then compare direction, magnitude, path and entry/exit economics separately on the same eligible periods. Reuse existing models and nearest prior experiments; record the material difference before another fit. A negative comparison is useful evidence and can close a research question.
