# Corrected MA and compact technical comparison

This offline engineering experiment reuses the exact corrected MA feature slice and existing compact24 causal price transform. It does not load the old MA fitted artifact, change any running study, or reconstruct original historical feature availability. The source snapshot contains observed archived M1 mid and bid/ask OHLC; its original ingestion and midpoint convention are not attested.

The authoritative backlog and recovery reconciliation put the MA grid after the recovered second-ridge comparator. They also require explicit feature availability, matched baselines and honest costs. The prior dictionary describes historical capacity; its older live-version/history-limit statements are dated context, not this experiment's protocol.

Before any model scores, the design fixes three pairs (EUR/USD, GBP/USD and USD/JPY), targets15/30/60minutes and three learned arms: corrected MA643, existing compact24, and their667-column concatenation. Corrected feature values are a new version; retained old fitted-weight compatibility is unproven. Features are standardized jointly within each arm using initial training rows only. Constant training columns are disclosed, with scale1; nothing is imputed or selected by test outcomes.

Every adjacent missing minute starts a new session. All sessions with204 completed real rows contribute warmed origins on the fixed UTC five-minute label grid. EMA initialization resets at the actual session start, with every prior row in that session retained. Both feature families use the same eligible origins. Targets must exist at exactly reference price time plus the native horizon within the same continuous session. Bar labels and price availability differ by60seconds. Gap, warm-up, grid and target exclusions are counted.

Per-pair cutoffs divide the actual first-to-last price-clock range into60/20/20percent, floored to minutes. Every arm and horizon shares those two cutoffs. Training labels must mature strictly before the validation cutoff, and validation labels strictly before the test cutoff. Feature context can use already earlier rows across a split boundary; labels cannot overlap the following split. No rows are moved to repair a short split. A cell requires256training/64validation/64test rows or remains unsupported.

Ridge candidates use alpha0.1,1,10,100,1000 and an unpenalized intercept. Validation MAE chooses alpha, exact ties favor stronger regularization. Models and scalers remain fitted only to the initial training block, with no training-plus-validation refit. All pair/horizon selections are durably written before any final-test prediction or score. Final test is evaluated once. No test result chooses a family, threshold, subgroup, horizon or deployment.

Fixed comparators are zero return and last60-minute momentum scaled linearly to the target horizon. Targets/predictions/MAE use basis points relative to the original archived midpoint close. Directional accuracy excludes neutral predictions and zero outcomes; no probability model or Brier statistic is invented. Bid/ask endpoint costs retain a separate validity and non-neutral denominator. They do not establish original tradeability, a fill, timing delay, financing, slippage or dollar sizing.

Matched UTC-date reports compare each learned arm against zero, momentum and the compact arm where distinct. MAE improvement is baseline minus model error. Directional differences require the same nonzero outcome and two non-neutral predictions; zero return therefore has no directional comparison. Cost differences use the same valid bid/ask endpoints, treating a neutral no-position comparator as zero hypothetical return. A95percentile MAE interval is shown only with at least10test UTCdates, resampling whole dates1,000times with seed20260909. There is no across-pair pooling; if pooling is added in a future version, the same date draw must apply across currencies. Intervals are unadjusted descriptive multiple comparisons and do not authorize a model choice.

Bounds are100,000source rows/20MiB per pair,20,000grid origins per pair, one linear-algebra thread and600seconds for the actual run. A budget failure preserves partial evidence and requires a separately declared follow-up; gates are not relaxed after looking at results. No confidence interval or row count is described as independent-sample evidence. The implementation, test source, dependency versions, source snapshot and exact policy are bound in a pre-evaluation JSON receipt.
