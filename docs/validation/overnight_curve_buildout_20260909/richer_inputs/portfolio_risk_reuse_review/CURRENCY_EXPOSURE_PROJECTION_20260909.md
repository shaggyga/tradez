# Valued currency exposure projection — September 9, 2026

`oanda_currency_exposure_projection_v1.py` adds a pure research diagnostic for EUR/USD, GBP/USD and USD/JPY. It does not manage positions or issue orders, and it is not integrated into any active source registration.

Call `project_exposure(positions, candidate=None, *, quotes, metadata, limits, scenario_id, decision_epoch, observed_epoch, expected_source_bindings)`. `source_bindings()` returns the four module-load source identities: this module, the frozen replay/USD primitives, their frozen legacy dependency, and the strict signed-currency identity contract. Projection performs no file/network I/O. Caller record hashes and observation clocks remain attestations, not authenticated broker holdings or actual computation receipts.

Each position requires a unique ID, one shared scenario ID, explicit side±1, positive integer base units, source-record SHA, and original open/state-availability clocks. An optional candidate is an additive same-scenario what-if with its own source/availability. Every row is retained or the entire projection raises an error; no unvalued position is omitted. Exact metadata for the three supported pairs and explicit limits are mandatory. Quotes use exact decimal bid/ask text, actual market/availability clocks, source-record SHA and explicit tradeability. Both clocks must be no later than the original decision, even if the diagnostic is serialized later.

The two legs are **current-mark FX risk-factor sensitivity**: signed base units and their opposite quote units at the current pair midpoint. They are not financed-entry cash balances, NAV, margin, leverage or a loss forecast. USD midpoint valuation uses direct midpoint or inverse midpoint consistently; absolute risk uses conservative USD purchase cost from bid/ask. Reported gross currency-leg attribution counts both economic legs by design and remains separate from gross position notional. Net cancellation does not hide gross exposure or position counts.

Before/after outputs include per-position notional and marked legs, per-currency gross long/short/net amounts and conversions, source quote IDs/hashes, count capacity, gross-position notional, currency gross/net and leg-share limit breaches. All limits are caller-supplied diagnostics; zero caps remain restrictive. No threshold was selected using paper results. Currency overlap is not correlation or independent confirmation, and separate counterfactual arms must never be combined as one book.

66 focused tests passed, with zero failures/errors/skips. The sole warning was an existing pytest cache-directory permission warning. Cases cover direct/inverse USD orientation, same-size and unequal offsets, shared USD candidate concentration, exact limit boundaries, missing/future/stale/nontradeable inputs, fractional clocks, immutable caller inputs, low ambient Decimal precision, bounded scope and every inert output flag. Tests used synthetic data only; the retained example is explicitly synthetic. Existing frozen sources were imported read-only and their known hashes remained unchanged. No live state, broker request, fitting, active integration or policy modification was performed.
