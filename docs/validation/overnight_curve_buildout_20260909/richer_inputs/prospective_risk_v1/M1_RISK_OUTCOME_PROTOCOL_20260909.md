# Prospective M1 risk-distribution outcomes

The new `oanda_m1_risk_distribution_outcomes_v1.py` validates original issued, published and consumed records through the new distribution contract, then scores the two predeclared fixed-training methods across three horizons and twelve labels. It does not fit a model, make source requests, write runtime records or change the historical label engine.

`capture_future_m1(raw_bytes, receipt, metadata, *, clock)` independently replays the authoritative M1/MBA mapper and exact CSV parser. It retains original raw bytes, receipt, metadata, mapping proof and parsed rows. The new derived-observation clock is sampled after mapping/parsing/body construction; the original source read and completed-capture clocks remain separate. Validation replays those original bytes and receipt. This derived seal is not a new historical source arrival.

`score_distribution_from_captures(issued, publication, consumption, captures, *, input_raw, input_receipt, metadata, fit_raw, expected_source_bindings, as_of_epoch, clock)` revalidates the full original input, fixed-fit artifact, issue and publication/consumer chain. Every source must be available by the evaluation cutoff. The computation-completion clock is sampled after scoring. At most128 captures and128MiB of derived evidence are admitted in one call; each capture is bounded to4MiB and300 rows. A retained-file orchestrator should validate source inventory once and supply the relevant instrument/target domains rather than repeatedly processing unrelated sources.

Selection sorts original source read completion, then stable raw/receipt identity. Derived replay clocks never replace original source order. Each label uses its earliest decisive source, including an explicit missing target or missing complete path. Later favorable or more complete data cannot replace a decisive earlier omission. Query domains are not merged.

Endpoint labels require the attested source domain to cover the exact original target label. Path labels require coverage from the first future minute through that target. Their actual rows must be consecutive and complete; no bar, bid/ask value or price is filled. An endpoint can remain measurable while an interior gap withholds path labels. A future query need not contain the original reference row because the full original issue supplies that row. If a later source revises it, the difference is disclosed and the originally published reference remains in use.

Metrics are pinball loss at0.1/0.5/0.9, median absolute error, central interval width/coverage and lower/upper misses. Signed quantiles are not direction probabilities. Candle close and OHLC excursion envelopes do not prove executable fills, barrier order, tradeability or position-management efficacy. Current official-M prices retain the explicit caveat that historical training midpoint ingestion equivalence is unknown.

`aggregate_reports(reports, *, as_of_epoch)` checks report seals,72-node inventory, original targets, quantile metric arithmetic, cohort/source consistency and repeated issued identities. It selects the latest observation for each issue. Repeated same-pair/origin issues retain the earliest actual issue/consumption, with all additional identities explicitly excluded from extra sample counts. Empirical and volatility-scaled comparisons use the same original label/source denominator. Missing values remain null and methods/labels/horizons are not independent observations. This summary checks retained report consistency rather than independently authenticating report origin; unissued scheduled attempts require separate worker dispositions.
