# Offline pilot evaluator V3

The new external evaluator preserves the original rolling source election and numerical scorer. It validates each derived capture once into exact canonical bytes and recursively immutable parsed values. Opaque factory-bound references expose only scalar coverage/read fields. Three optimized pure paths reuse validated semantics, the exact semantic hash, and a sorted index of real bar labels. Original supplied-source checks, duplicate conflicts, ordering/reasons, current maturity, per-view reports and numerical formulas remain unchanged. Ordinary evidence and capacity overflow take the original path.

The final source passed 25 focused cases and independent source review. Tests cover full report equality, provider omission and entry-cost support, tampered evidence, future clocks, mutable caller data, recursive immutability, forged reference identity, hash collisions, capacity fallback and alias restoration.

The first comparison reused byte-pinned V1/V2 outputs and the saved 1,538-call actual V1 clock trace. Every source, attempt, curve, matched comparison, election and score matched. File bytes/identities matched; actual file-read observations remained separate. Its roughly 11% time reduction compares different runs under potentially different machine load. The benchmark source is preserved; the final source adds only the reference-identity spoof guard, covered by the full final tests and second differential.

The second comparison selected the first 12 verified curve files in the existing hash-sorted order, without inspecting performance. Their complete original proofs and all same-pair source observations were copied into a new private mirror: 2,158 files / 69,601,013 bytes. Unrelated attempts/curves were explicitly omitted. V2 used actual clocks; V3 replayed all 1,460 calls and matched every result. Supplied capture sets ranged from 3 to 131 per curve. Total time was nearly unchanged, while rolling scoring was about 14.3 times faster. Preparing all source captures dominates this small subset; the component improvement is not a fourteenfold whole-program speedup. No full current V3 run was performed.

The wide-source bank retained 10,454,948 canonical bytes and 43,169,154 accounted object bytes without overflow. Caps are 64 MiB canonical bytes, 256 MiB accounted objects and 2,048 entries, plus the existing separate 64 MiB validation memo. Accounting includes proxy backing dictionaries and per-entry overhead; it is not a hard process-memory cap. Failures, whole scores and current-clock decisions are not cached.

The initial wide-source plan-only invocation hit the frozen per-curve size limit on a five-megabyte evaluator manifest. Before any mirror/evaluation was created, only the new external benchmark reader was corrected to use a bounded 16 MiB stable-identity read. No frozen source or limit changed.

Use remains a separate synchronous process with non-overlapping evaluation sessions. Source pins bracket execution and scoped aliases restore. No GET, fit, forecast issue, order, live-runtime write, registered-source edit or accuracy claim occurred. Timings exclude final report serialization and are not guarantees for future inventories. Native horizons, midpoint conventions and outcome denominators remain unchanged.

For workload context only, the prior V2 actual003 evaluation covered 866 verified chains plus 30 withheld curves in 916.13 seconds, with 1,922 cache evictions. The later 08:32 completion poll was not the end time.
