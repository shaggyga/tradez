# Timed forecasting continuation

The shared Vault's `FOREX_FORECASTING_CONTINUATION.md` and `REVIEW_QUEUE.json` define
the current forecasting alternatives. Read them with `FOREX_TIMED_PROMPT.md` when a
duration is requested. This page is a portable entry point, not a duplicate queue.

A blocked experiment stays logged with its dependencies; continue independent
eligible forecasting work for the remaining time. Resume runnable partial work first.
Missing protected-confirmation data does not block further development on retained
data. Record versioned run settings and honest evidence labels; no project-wide
freeze or additional approval is implied. Keep operational work limited to necessary
defects and the required handoff. Reuse completed models and results.

At package boundaries replenish supported candidates from the full design. Before
stopping early, log the branch scan and actual blocker/platform limit. Preserve the
original start/deadline through context changes and leave exact resume instructions.
This document prepares future runs; it does not start one or guarantee platform uptime.
