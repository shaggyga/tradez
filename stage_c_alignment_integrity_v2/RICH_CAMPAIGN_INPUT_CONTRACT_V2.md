Expands the verified canonical 216 technical plus 12 peer calculators to the original 76 six-hour campaign origins, July 8-26, 2024, for all 68 pairs. Each origin uses up to 603 original elapsed bars. The retained archive is hash-verified; original OHLC, activity and bid/ask values are used without fabricated support. Source gaps and missing fields remain explicit. Availability is the declared historical completed-bar-end assumption, not an observed receipt or publication timestamp.

Original legacy observations, exact endpoint outcomes, strict-path outcomes and blocked session-calendar records remain byte-value equivalent to the earlier technical evidence. Current quote-wing costs and source minute/member identity must agree before publication. Outcomes are written separately from feature records. No model fit, outcome recomputation or trading action occurs.

Four ordered feature-only views are supplied: legacy26, compact38 plus two current costs, compact50 plus two current costs, and full228 plus two current costs. The full view has 230 inputs, not 228 independent signals. All groups preserve the same pair/origin universe and the original legacy eligibility flag. Missing rich inputs stay None with masks. Learned imputation, scaling, missing-indicator design and selectors belong to a later training-prefix artifact; no full-history transform or future2026 normalizer is applied here. Names alone do not admit old weights.

The previous eight-origin sample has 544 externally preserved original record hashes. Wider context must reproduce those exact records. Additional tests check all original observations/outcomes, current costs, prefix causality, minimal support, view order, unavailable as-of clocks, identity/source drift, exclusive publication and real process-death recovery.

Routine operator: rich_campaign_operator_v2.py status/run/resume/verify with the externally pinned recipe SHA and explicit --input-root, --preparation-contract, --lineage, --technical, --trad-root and --runs-dir. Isolated Python mode is supported; numerical imports follow source/dependency preflight. A matching completed run is verified, while an incomplete identity uses explicit resume. Review-required results must be preserved and escalated, not repinned.

The compact checkpoint requires the existing raw archive identified in REQUIRED_ARCHIVE.json. It does not duplicate that archive or include the larger generated OHLC slices. Restore verifies the archive, recreates exact slice bytes/manifest, restores the original completed technical evidence from a bounded nested package, rebuilds the rich inputs and verifies payload parity. Existing outer ZIP guards remain unchanged, and the nested technical package is limited to 72 plain members, 8MiB/member and 32MiB total. No original absolute path is needed; pass the archive's equivalent local path. The checkpoint does not refit or replay all historical model studies.
