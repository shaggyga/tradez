coverage gap from an untested assumption that truncation explains the failure.
Non-ASCII ratios are diagnostics, not language identification.

Four original pure functions are recovered as exact source-line fragments from
the C-drive collector: clean_text, explicit_policy_decision_action,
policy_direction_text and semantic_claim_decomposition. Their full original
source hash, line ranges and fragment hashes are preserved. Only these frozen
functions and stdlib dependencies execute; the live collector is not imported.

quotation, historical recap, conflicting actions, decimal conditions, mixed
issuer context and negated claims. These failures are expected audit findings,
not passing semantic acceptance. Native outputs are blocked from feature
admission. Native rate_currency_sign is never adopted as FX direction.

issuer, assertion, units or vintage. No surprise is computed or missing value
imputed. Exact source spans are resolved conservatively; cleaned-only text that
cannot be found in original bytes stays unresolved.
