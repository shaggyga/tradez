## Review repair MT-R01 / MT-R02

Clause boundaries preserve decimal dots and a fixed list of common abbreviation
dots. This conservative lexical rule does not claim complete linguistic parsing.
Same currency/event/class versions are first filtered by availability. Identical
material at the latest clock coalesces with all references retained; conflicting
material at the same clock produces an explicit ambiguous state, null axes and
null change. Content hashes never select the semantic winner. A strictly later
available version can resolve the earlier ambiguity for later views only. If a
prior event is ambiguous, current-minus-prior change remains unavailable.
Returned axes are detached from source records. Source publication/currency/class
and exact retained text define material identity; mirror URLs do not define stance.

true punctuation boundaries,40 URL variants in both input orders, later revisions,
identical mirrors, ambiguous prior changes and nonmutating views, as well as the
original actual consumer and crash/recovery checks. Original recipe/output and
