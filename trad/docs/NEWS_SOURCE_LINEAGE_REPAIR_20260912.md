# News source and derived-availability repair — September 12, 2026

The existing collector had299 retained source-table/payload mismatches among5357 inspected articles. Cross-query deduplication was intentional, but later payload replacement could leave table source fields unchanged. The repaired core keeps coherent active source fields and five additive evidence tables: source versions, source observations, first canonical origins, changed canonical projections and derived classification observations. Exact incoming classified mappings can be reconstructed; raw HTTP bodies and missing old query history are not invented.

Source availability, later classification availability and original story age now have distinct clocks. New classifications require an explicit attested post-computation clock. Neither reclassification nor a query-only change refreshes an unchanged story's age. Admission uses the later availability floor; decay and expiry use original source evidence. New guardv2 retains exact validation dispatch for old guardv1 evidence. Old first-seen/publication/provenance and unresolved legacy origins remain preserved.

Source and classification writes retain refusal evidence when clocks are missing, naive, backward or unattested. Such work cannot update the active article. Source polling validators and cadence are restored after refusal so a later trusted poll can retry. Reclassification uses compare-and-swap against the original payload, preventing a stale computation from overwriting a newer same-source update. Savepoints preserve caller-owned transactions and make article/topic refresh roll back together. Five evidence tables reject update/delete/conflicting replacement while allowing identical retries.

The independent source/caller suites passed63source tests,22derived/guard tests and28full-module tests with actual collector/classifier functions and synthetic clocks/fetches/SQLite. These scopes overlap. Earlier failed snapshots and regression probes remain preserved, including the origin-retry regression introduced by stronger replacement guards. A canonical copy of the28-case suite is retained as `test_oanda_news_source_lineage_v1.py`.

Their compatibility, whole legacy-suite accounting, live storage growth, full process/package/source closure and prospective publication evidence remain open. Historical missing query observations remain missing. This repair establishes source/timing behavior, not predictive accuracy or profitable trading.
