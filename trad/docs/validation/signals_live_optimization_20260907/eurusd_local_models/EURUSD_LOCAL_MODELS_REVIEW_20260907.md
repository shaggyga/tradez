# EURUSD-only research companion

`trad/oanda_eurusd_local_models_v1.py` provides `predict_all(rows_by_epoch, cutoff_epoch)`. It receives only the real EURUSD M1 timestamp-to-close map, with at most 1,024 retained rows. Keys and cutoff are UTC minute starts; close and label-maturity diagnostics add 60 seconds. The cutoff must be the latest actual row, with all 61 current EURUSD closes present. No peer maps are accepted, fabricated or required.

The two available output families are exactly `ridge_return_repaired` and `probabilistic_state_space`. The standalone implementation preserves gap_v2's formulas: ridge alpha 10, UTC stride three, at least 24 mature labels, training-only scaling and complete 121-price feature/target windows; EWMA alpha 0.08, reset at the latest EURUSD gap, at most 256 consecutive prices and at least 60 returns. Missing exact targets are rejected, never replaced with the next array row. Valid retained Friday training segments remain usable after actual current capture.

The helper imports only NumPy and standard-library modules. It neither imports the seven-pair worker nor duplicates EURUSD into fake peers. It does not observe availability, publish forecasts, persist weights, open files/databases, start workers, call a broker or grant execution authority. The separate input/ledger/worker integration must verify source identity and duplicates, capture actual availability, require both families, and retain later completion/issue/publication clocks and the original H1 target.

Validation: 54 offline tests passed in 4.33 seconds. Expected values and probabilities exactly match frozen gap_v2 ridge/EWMA on continuous, Friday/Sunday and historical-hole fixtures. Tests show that missing AUD/USD, NZD/USD and USD/CHF minutes can block the four-family study while leaving the direct EURUSD result unchanged. Additional checks cover exact label timestamps, training-only scaling, chronological disorder, 24-label boundary, current-window gaps, state resets, bounded rows, malformed/future input, numerical overflow, immutable parameters and false authority flags.
