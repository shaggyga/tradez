# Native curve outcome API

This new pure module scores original published/consumed research curves after actual source receipt. It acquires no data, opens no database, changes no source/registry, and cannot place orders. The focused final suite passed47 cases. The retained synthetic fixture demonstrates arithmetic and evidence boundaries, not current market performance.

`capture_outcome_candles(rows, *, instrument, source_sha256, coverage_start_label_epoch, coverage_end_label_epoch, complete_range, read_started_epoch, read_completed_epoch, source_attestation, clock)` seals supplied complete S5 rows. Each row has `bar_start_epoch`, `available_epoch` equal to the actual source read completion, `complete=True`, and exact string/integer `mid_close`, `bid_close`, `ask_close`. The price-close clock is label+5. The response must contain1–4,096 strictly increasing unique complete rows, bounded by the shared2MiB JSON contract.

The separate source attestation has instrument, granularity S5, raw_source_sha256, complete_provider_response=True, coverage_start_label_epoch, coverage_end_label_epoch, read_started_epoch, read_completed_epoch and source_receipt_sha256. The registered caller must verify this mapping against retained raw provider response and its actual capture receipt. The pure function cannot authenticate network I/O. Coverage is only between the first and last returned complete row labels. Gaps inside that source-attested response domain are reported missing; no before/after-domain absence or filled candle is inferred.

`capture_entry_quote(quote, *, source_sha256, clock)` records an independently observed, explicitly tradeable pricing quote. Exact bid/ask are required; market time cannot exceed availability/observation, and quote age at actual observation cannot exceed60 seconds. This is independent of the candle capture; no tradeability is inferred from MBA candles.

`score_curve(curve, publication, consumption, candle_capture, *, expected_source_bindings, metadata, clock, entry_quote=None)` validates the complete original receipt chain. Non-current engineering/synthetic chains cannot become prospective evidence; unpublished, invalid, future or excluded-at-issue records do not contribute scores. Current metadata must specify instrument/base/quote/pip. The issued `prepared.input_context.price_convention` must explicitly choose official_midpoint or ba_derived_midpoint. Official M and exact BA close prices are both retained, and the selected target follows the issued convention. Historical ingestion equivalence is not inferred.

Each native node has two separately labeled views: nominal_exact uses only its exact nominal label; retained_training_target selects the first real complete source bar at/after nominal through the original inclusive delay bound (the recovered model uses0–7 seconds). Each view retains actual selected label, close-price clock, delay, source row availability and later outcome availability. The original target is never rewritten. If the response does not cover the necessary domain, missingness is explicit. A probability scored at nominal when the original model used a nonzero target window is explicitly an event-mismatched diagnostic.

Metrics retain actual return in bps, current-instrument and native-model pips, MAE versus the zero-move baseline, original predicted/actual sign, and original uncalibrated strict-up Brier. Zero outcomes are not-up for Brier but remain separate from directional accuracy; neutral predictions are not hidden positions. No conditional remaining-return probability is fabricated.

The optional entry must be independently read after curve consumption and before the original nominal target, even when its recent market tick predates publication. A backfilled old quote timestamp does not establish earlier availability. The caller must bind actual current-generation raw source evidence. Bid/ask endpoint results use long(terminal_bid-entry_ask)/entry_ask and short(entry_bid-terminal_ask)/entry_bid; the two denominators are distinct. This section retains the API key `executable` but its status is `scored_bid_ask_cost_diagnostic`: target_tradeability_observed=False and broker_execution_observed=False. Completed candle closes do not prove an executable exit, broker fill, or management-policy success. No slippage, financing, commission, USD position sizing or leverage is fabricated.

`aggregate_reports(reports)` groups by view, price convention, model artifact, cohort and native horizon. It preserves all missingness, zero/neutral counts and separate direction/probability/entry denominators. Duplicate curve/node/view records are refused. The output reports unique curve/reference/instrument counts and leaves independent_sample_size unknown: horizons, pairs, views and successive forecasts overlap.

The initial41-pass/two-failed fixture run is retained. Both failures came from trying to construct engineering/synthetic issuance after the parent contract had already prohibited that. The corrected fixtures verify that prohibition and rejection of a forged chain. No earlier forecasts or outcomes were changed.
