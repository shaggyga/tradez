# Recovered second-ridge inference adapter

`trad/oanda_recovered_second_curve_v1.py` now provides a pure, read-only path from 13 complete real S5 bars to the existing 13 trained horizon predictions. It does not import or instantiate a fitter, trading executor, store or runner. It reads only the original verified JSON checkpoint, preserves its 14 features and standardized coefficient transform, and always returns `computed_not_issued` with order, account, authorization, promotion and proof eligibility false. The current frozen study sources and models were not changed.

API:

- `load_model(path)` verifies the exact recovered artifact and both original implementation hashes. Private immutable factory contents bind every cell and metadata field; a copied dataclass carrying a valid artifact hash but modified coefficients is rejected.
- `capture_s5_rows(rows, *, instrument, pip_size, source_sha256, clock, scope='engineering_replay')` requires exactly 13 true-complete real five-second bars, actual retained availability clocks and explicit pip metadata matching the original trained-unit table. Missing bars, reordering, duplicate bars, nonfinite fields, future observations, spread/unit mismatch and altered sealed fields are rejected. The supplied source digest is explicitly caller-provided; the rows and derived features are independently sealed and replayed, not represented as reread from that source. `current_research` adds a 30-second latest-completed-bar freshness limit; engineering replay is explicitly separate.
- `predict_curve(capture, model, *, clock)` preserves all original horizon nodes, expected pips, retained residual standard deviation, uncalibrated residual-logistic probability and pair/proxy provenance. It samples actual computation start/end and checks freshness again. It supplies no issue timestamp or publication authority.

The S5 label `t` is distinct from its completed price clock `t+5`: output retains `reference_label_epoch=t`, `reference_price_epoch=reference_epoch=t+5`, `target_label_epoch=t+h`, and `target_price_epoch=target_epoch=t+h+5`. This preserves the original trained horizon `h`. Publication later must retain these native target clocks and withhold already-expired nodes, rather than resetting targets relative to issue time. The reference availability must be at or after the completed price clock.

The fixed artifact was fitted on July 31 at 15:44:22 UTC. It contains 68 pairs and 884 nodes: 67 pairs have pair-specific fits; TRY/JPY has 13 explicitly labeled pooled proxy nodes. The adapter strips execution profiles and grants no authority based on historical artifact eligibility. Residual scale is not a calibrated interval or demonstrated risk bound.

Validation: **46 focused tests passed**. They cover the actual retained EUR/USD input, all 14 feature formulas, all 13 predictions against an independent 80-digit Decimal formula, integrity/replay/pip/clock/gap failures, model-object spoofing and prohibited SQLite/network use. The real selected strict-grid input agrees with the original pure training transform to **1.46e-11 maximum feature difference**. The first run's two failures remain recorded: one test assertion confused a false `execution_profiles_included` metadata field with retained profiles; the original smoke's latest eligible origin contained an interior missing five-second bar and was correctly rejected. The real test now chooses the latest exact-grid origin using timestamps alone. No outcome selection or fitting occurred. The old NumPy transform warning about UTC-string representation is retained; the new adapter explicitly parses numeric bar/availability epochs supplied from timezone-aware input parsing.

Post-fit input availability is a remaining prerequisite. Canonical C has no `candles_s5_bam` directory. Retained derived S1 features do exist in D's `second_forecast_live_v1.sqlite` at August 3, 20:45:30 UTC and `second_forecast_microstructure_v1.sqlite` through July 31, 16:11:20 UTC. Those are derived feature snapshots, not original complete S5 candles. The old live S1 buffer forward-filled missing seconds, computed range from sampled mids, counted quote activity instead of S5 volume, and omitted seconds in its time-of-day feature. Therefore this adapter does not claim S1/S5 transform equivalence or reconstruct missing raw input from those snapshots.

A future pilot can use this layer once independently observed complete S5 input is provided and the root's curve contract records original targets and actual publication/consumer clocks. The current result establishes inference compatibility only, with no prospective-performance, out-of-sample, profitability or live-readiness claim.
